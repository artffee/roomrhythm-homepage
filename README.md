# Room Rhythm homepage

Public design preview for [getroomrhythm.com](https://getroomrhythm.com/). The production site is maintained in artffee/room-rhythm.

The guest/staff demonstration runs entirely in browser memory with fictional Room 305. It sends no messages, stores no guest data and resets on reload. The rental guide is an illustrative sample. Pilot links open the owner’s email app; launch-list and privacy links go to the production website.

This preview has no analytics. Production retains its existing privacy-aware analytics and private launch-list handling. The homepage update does not activate email delivery or deploy the separate hotel application prototype.

Serve this directory over HTTP to test the ES modules. No build or dependencies are required.
